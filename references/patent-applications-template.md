# Patent Applications Document Template

A companion document to the business plan, listing plausible patent application angles found while researching the idea. Produce one only when research actually turns up a novel mechanism, method, or technical feature worth flagging — a pure business-model or branding idea usually won't have one, and forcing an empty document isn't useful.

Open the document with this disclaimer, unedited:

> **Not legal advice.** This is a prior-art landscape scan done with web search, not a patentability or freedom-to-operate opinion from a qualified professional. Consult a registered patent attorney or agent before filing an application or relying on any assessment below.

Then one entry per plausible application angle, using this structure:

## <Working title for the angle>

- **What it covers**: the specific mechanism, method, or technical feature — not the business model or a vague restatement of the whole product.
- **Prior art found**: patent/application number, holder, filing or grant date, and a one-line description of the overlap, for each relevant hit. If none was found, say so explicitly rather than omitting the field.
- **Preliminary read**: adjacent art (similar space, different mechanism) vs. possible freedom-to-operate risk (the business might infringe if built as described) — labeled as a preliminary read, not a conclusion.
- **Recommended next step**: e.g. "provisional application candidate — consult a patent attorney," or "likely not patentable on its own; document as a trade secret instead."

Repeat for each distinct angle. Close with:

## Sources

- Every patent database link and search consulted, so the scan can be re-verified or deepened later.
