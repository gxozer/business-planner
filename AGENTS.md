# Agent Development Practices

## Documentation

- On first use in any document, expand acronyms to their full name.
- Keep documentation concise, clear, and continuously up to date.
- Use Mermaid for diagrams in Markdown files, rather than ASCII art or embedded images.

## Ground Rules

- Ask clarifying questions when instructions are unclear rather than guessing.
- Never commit or push code.
- Never transition Jira tickets past **In Review** — leave the final move to **Done** to the user.
